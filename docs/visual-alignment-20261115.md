# BoardUI 手机视觉与当前 App 对照审查

审查批次：2026-11-15。只读浏览器审查，未修改业务代码、未发送模型请求。视口固定 390×844；这是桌面 Chrome 的手机尺寸检查，不是 iOS/Android 真机。App 在审查过程中仍有并行修改，本文以最后一组 verified-dimensions.json 与 app-chat/app-sidebar/app-results 截图为准。

## 结论与入口

公开手机页面的结构和交互证据已经获取；**没有恢复 BoardUI 私有原始 TSX 工程，也不能把当前 App 说成原模板所有功能的原样复刻或像素级一致。** 公开模板包含大量演示数据和空动作；本 App 的任务是用独立实现承载现有 Runtime 的真实业务。此前 research README 已明确这一边界。

实际入口：[组件说明](https://www.boardui.com/zh-hans/components/ai-chat) → 点击“实时预览” → [完整聊天模板](https://www.boardui.com/zh-hans/templates/ai-chat)。本次实际读取链接确认 URL；组件页没有 iframe，是组件在文档页面内渲染。对照应使用完整模板，不能把组件文档页当作手机 App 主页面。

模板的 Pro 推广提示延迟出现，会遮挡输入器；使用页面自带“关闭 Pro 模板提示”按钮后继续采集。没有访问付费源码接口。

## 尚需处理的具体视觉差异

1. **结果面板先展示实际结果。** 复现：App打开“官方 DeepSeek 真实验证”→右上“结果”。当前整段审批测试提示变成多行粗体标题，绝对路径工作区卡也占很大高度；第一屏几乎看不到代码正文。建议任务标题最多两行，工作区路径可折叠，文件条和增删计数放上方，当前文件代码默认展开。依据 app-results.png 与 reference-changes.png。
2. **窄输入区占位文字裁切。** 复现：390×844打开已有会话、输入框为空；app-chat.png 中占位第二行露出。原模板用单行 input 与渐隐遮罩，App需在保持多行实际输入能力时控制空占位的一行显示。
3. **模型选择形态尚未对齐。** 原模板在输入器上方弹出紧凑模型菜单和推理力度条（reference-model-menu.png）；当前 App 的“模型与推理”仍是较大的底部设置面板，含提供商与模型ID。运行选择真实模型比演示标签更重要，但可把常用模型/力度放紧凑菜单，高级ID移到二级设置。此项App形态由源码main.tsx核对，未额外触发模型刷新。
4. **导航分组不同。** 原模板按仓库→会话树组织；App目前按最近/归档平铺。可按已有thread.workspace分组，保留已有搜索和归档行为；不要复制示例仓库、团队或订阅身份。
5. **附件菜单宽度和分组不同。** 原模板上浮菜单接近整个聊天宽度，包含文件/文件夹、目标、计划，以及Documents/Spreadsheets/Presentations/Code blocks入口。当前App源码为250px菜单，已接真实上传/文本/电脑文件/模式，未对齐整组文档快捷入口。本次原站菜单已截图；当前App菜单以源码观察为证，不宣称执行过全部菜单动作。
6. **参考代码视觉仍缺项。** 原模板代码行号、语法着色、紧凑文件头是显眼特征；当前结果更多是折叠记录。这里应复用现有真实diff数据渲染，不能用参考模板固定“12项、+156/-23”代替事实。

## 重放步骤

原模板：打开完整模板并设置390×844 → 关闭Pro推广提示 → “打开导航” → 关闭导航 → “开放代码” → “变化”/“浏览器” → 关闭代码 → “添加附件” → Esc → “Fable 5”。

当前App：打开本机预览并连接 → 选一个已有会话（不发送消息）→ 截图聊天 → 打开会话列表 → 关闭列表 → 右上结果。已验证截图使用现有隔离测试会话，仅包含合成验证内容；本次没有执行工具、生成内容、安装依赖或改变业务数据。

## 本轮修复后的最终复核

以下更新覆盖上文“剩余差异”中已经修复的部分；原始审查记录及其截图保持原样，供前后比较。

- 手机主画布改为 12px 外距、圆角浅灰背景；移除常驻四项底栏，增强功能保留在侧栏及工作区面板。
- 导航实际为 260px 侧栏、主画布右移 272px、325ms 过渡；会话按真实 `thread.workspace` 分组，可展开折叠，保留搜索与最近/归档筛选。设置和外观位于侧栏底部。
- 输入器空状态实测 52px 高；占位文字改为单行“问我”，保留实际多行输入、上传、文本附件、语音、停止和追加指令。附件按钮收纳到加号菜单，未删除能力。
- 用户气泡使用原参考源码的 `max-width: calc(50% + 6px)`；助手正文去掉额外品牌头像头，保留复制与代码操作。
- 验证额度改为紧凑可展开提示；手动开放额度按钮仍需用户显式点击。视觉核查没有点击真实额度按钮，也没有提交模型消息。初次本地截图已显示手动剩余 6 次，本轮未改变该状态。
- 结果面板改为右侧全高抽屉，390px 视口下宽 378px。工作区绝对路径折叠；长任务说明限制两行；首轮首个实际文件差异默认展开，增加差异文本行序号及增删色彩。没有替换成参考模板的固定文件数或假统计。
- 模型按钮先打开紧凑快捷弹层，使用已有会话的真实提供商/模型；推理力度可直接调整。“高级模型配置”继续提供电脑模型目录、显式刷新与自定义 ID。
