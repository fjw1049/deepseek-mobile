# 手机会话状态边界审查（2026-11-15）

范围：main、输入器、上传、语音、模型选择和会话操作；参考已留存 BoardUI 手机截图，不重新抓站、不声称恢复私有 TSX。本轮没有调用付费模型。

## 已修复

- 统一会话切换保存/恢复文本和附件草稿；任务入口、分享/分叉跳转、Android 返回使用同一切换流程。切换立即清空旧详情，快照到达前禁止发送旧模型配置。
- 追加指令完成只清理来源会话草稿；慢重命名、删除、分叉和分享导入回调不再覆盖随后选中的会话。删除同时清理对应上传草稿。
- 离开会话时已开始的上传可能仍成功；成功引用回收原会话草稿，不串入当前会话。尚未开始的剩余文件不继续后台上传，并明确提示重新选择；原草稿已满 5 个附件时提示到工作区重新引用。
- 模型弹层取消恢复编辑前配置；保存结束仅影响来源会话。推理强度在切换会话时重置，避免串配置。
- 主弹层、侧栏、语音弹层支持 Escape、原生 Back 关闭与 Tab 焦点循环；主 Sheet 打开时背景不可交互。附件菜单支持 Escape、点外关闭。
- 录音关闭/后台后迟到的权限错误、停止回调、状态请求不再污染新弹层。沿用原录音 hook 的麦克风取消/释放逻辑。
- 恢复多行草稿和程序填入文本时，输入框重新计算高度，最大 120px。

## 验证

`npx tsc --noEmit` 通过。新增 `e2e/session-boundaries.spec.ts` 共 6 项，独立 5183/17882 端口测试，最终 6 passed / 0 skipped / 0 flaky，18.5 秒：

1. 延迟 steer 响应：保留 B 草稿，只清除 A 已接受指令。
2. 延迟重命名：等待原详情刷新完成后，B 标题/内容仍正确。
3. 延迟确认删除：等待列表刷新完成后，B 会话/草稿仍保留。
4. 模型取消、弹层 Tab/Escape/原生返回事件、多行草稿高度。
5. 延迟麦克风权限拒绝：关闭后重新打开语音弹层不会收到旧错误。
6. 真实隔离 Runtime 上传：延迟响应不会插入 B，切回 A 可见附件引用。

测试禁止 POST /turns；steer 和录音权限使用本地拦截，真实上传/元数据仅操作临时 fixture。测试未验证真机操作系统权限对话框、真实 ASR 服务或手机系统键盘；这些仍须签名真机验证。原生 Back 测的是 App 所用取消事件路径，不等于实际 Android 设备验收。

现有边界：关闭上传入口不会撤回电脑已接受的 POST；网络结果未知时不自动重发。文本附件本地读取上限 100 KB，现有卸载保护能防止串会话；本轮没有引入后台本地文本读取队列。
