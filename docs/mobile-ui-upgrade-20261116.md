## 01:04 截图后的产品交互复核（构建 2026111604）

截图暴露的三个问题不是使用方式错误，而是产品展示缺陷：用量落入通用 JSON 兜底；浏览器 inactive 时还展示残留 URL 和自动展开的遥控表单；深色侧面板安全区被更高优先级样式覆盖，标题跟内容一起滚动。

### 已修复

- 专用用量页用中文分项卡片取代 JSON；准确标注“本次电脑服务启动以来”，并非全部历史或当前聊天。源码依据：Runtime `get_session_model_usage` 过滤服务启动前完成的回合，另合并运行中的 ledger。
- 截图总量与输入/输出之和不符：前端明确提示统计异常，不展示误导总量，不擅自篡改源分项。费用零值显示“暂无有效费用估算”，不声称免费。后端历史统计口径仍待单独核验。
- 删除普通资源页直接输出 JSON 的通用兜底。工具执行记录默认展示中文状态，原始工具返回和 metadata 放入明确的“技术详情”。审批命令、文件正文、代码和 Git diff 仍保留必要原文。
- 浏览器加载/未打开/助手控制/用户控制分开呈现；未打开不展示残留 URL；网址只在活动状态显示网站名称；手动操作不自动展开，键盘操作再按需展开。必须有活动浏览器、有效截图、scene 和 generation 才允许遥控。
- 深色与浅色侧面板均以独立滚动内容区保留顶部标题和关闭按钮，避开 iPhone 状态栏。

### 主要功能逐项结论

| 功能 | 用户目的与入口 | 本轮审核结论 |
| --- | --- | --- |
| 配对/连接/撤销 | 首次连接自己的电脑；设置管理设备 | 明确区分连接、授权、外部能力配置；离线链路可验证，不是模型 Key 输入页 |
| 聊天/历史/草稿/停止 | 主对话完成任务 | 会话隔离与未知写入不重放保留；技术元数据不再作为正常进度正文 |
| 模型/运行模式/审批 | 发送前选择能力与权限 | 模型目录来自电脑；personal 服务固定模型与推理限制仍是能力适配缺口，不能把全部目录项等同可用 |
| 附件/语音 | 补充当前请求 | 附件按会话上传；语音缺凭据有明确提示。真实 ASR 与真机录音不在离线测试证明范围 |
| 任务/自动化 | 查看电脑工作、安排定时任务 | 列表、状态、结果、恢复审批、暂停/删除等使用专用界面；真实长期调度仍待运行验收 |
| 用量 | 了解模型消耗 | 本轮修复 JSON 展示及范围/费用误导；上游统计不一致仍公开标注 |
| 文件/Git | 查看成果、引用文件、管理版本 | 文件正文/diff 属于必要内容，不能为“去技术化”删除；写入保留明确操作及冲突处理 |
| 终端 | 用户主动执行电脑命令 | 仅项目工具内按需进入；这是高级能力，不应自动出现在聊天主流程 |
| 浏览器 | 查看网页任务，必要时协助 | 入口绑定使用浏览器的回合；画面按需打开；历史记录不冒充历史截图。接管/关闭/停止区分 |
| 电脑控制 | 查看桌面任务、交接控制权 | 手机任意鼠标键盘远程桌面仍未实现，不能称为完整远程桌面 |
| 技能/插件/MCP/记忆 | 管理电脑扩展与项目约定 | 有配置/权限确认与失败路径；未实际启用用户外部插件，未保证全部第三方服务可用 |
| 回退/分享/导出 | 恢复历史、交付成果 | 回退先预览冲突，分享先确认内容；真实外部分享与原生系统分享仍有验收边界 |
| 通知 | 在收到事件时提醒 | 是本地通知，不是可靠后台推送；系统挂起时不能保证送达 |

结论：接口接通不等于交互合格，离线测试通过也不等于所有外部服务真机验收。本轮覆盖主要可见入口、空状态、失败及返回路径，保留上述未完成项，未自动调用付费模型或运行个人外部插件。
