# 移动端结构与功能深审（2026-11-15）

## 代码归属

8个移动适配模块迁入原Runtime `src/deepseek_tui/mobile/`，由包入口统一挂载和关闭。server仅保留挂载、生命周期和鉴权接点，没有server/mobile_*转发壳。URL及协议不变；独立App继续复用一个Runtime、共享Git及PTY实现。

## 本轮发现并修复

- 追加指令、会话设置/删除/分叉/分享慢响应串入其它会话：绑定来源会话，统一跳转保存草稿，等待新快照时禁止发送旧配置。
- 上传中切换会话后成功附件引用丢失：成功结果回收到来源草稿；未上传部分明确提示，不自动重发。
- 模型取消仍保留临时选项：取消恢复原配置。
- 弹层返回键/焦点不一致、麦克风权限迟到：统一关闭与焦点约束，失效录音不写草稿。
- 多行草稿恢复高度错误：恢复时重新测量输入区域。
- Git无首次提交时整页报HEAD错误：修复共享Git服务的空仓库分支判断与空树diff，支持首次暂存/提交。
- 部分暂存差异混在一起：分别显示将提交与未暂存内容；失败关闭旧确认并刷新，不重放写入。
- 浏览器鼠标/键盘按下后请求失败：只释放状态，不重放操作；旧画面不覆盖新画面。
- 终端写入结果未知后继续接收输入：明确暂停输入，显式只读重连；创建结果未知时先查询，不能直接重复创建。
- 通知持久化失败可能重复提醒：增加有界内存去重。
- 技能安装/MCP保存：提交函数内也检查显式确认。
