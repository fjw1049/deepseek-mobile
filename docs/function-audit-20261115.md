# App 功能验收（2026-11-15）

本轮继续在独立项目 `deepseek-mobile` 实现。手机通过 HTTP/SSE 调用现有 Python Runtime；文件、模型、工具、记忆、任务与自动化仍在电脑执行。新增受限的移动端接口，并将桌面 PTY 核心抽成共用模块，没有另写执行引擎。BoardUI 只作为公开界面参考，未恢复其私有完整源码，也未把第三方编译 bundle 纳入发布资源。

- 官方 `https://api.deepseek.com` / `deepseek-flash`：6次生成请求，全部HTTP200。图片/PDF/Office理解、真实追问、授权后写文件、停止和历史同步通过。前端pageerror为0。
- 第6次为中途停止，未获得最终usage；不把不完整usage当作总费用。未调用Pro，未自动回退。
- 真实调用记录：`artifacts/full-live-20261115/provider-report.json`；界面记录与截图：同目录 `ui-report.json`、`real-*.png`。
- 原生构建和产物精确状态以 `artifacts/verification.json` 为准，源码/编译不替代真机验收。

## 仍有明确边界

1. ASR等待电脑端凭据，遵从用户“沿用原系统ASR”选择；没有拿聊天Key冒充语音服务。
2. 真机键盘、分享、Keychain/Keystore、通知和网络恢复尚未实测；没有开发者账号，未签名提交iOS商店或Google Play，未上线。
3. 手机任意远程桌面输入、系统挂起时的可靠后台推送尚未实现；不能把当前CUA接管和本地通知称为这两项。
4. 浏览器的完整录屏/工作流演示、所有桌面专用设置和外部插件行为并非全部搬到手机；当前功能范围以上表为准。
5. Mac mini 常驻部署、Tailscale和公网网络按用户顺序后置。服务写操作不自动重放；尚无跨所有旧接口的通用幂等/对账协议。

## 验证入口

电脑打开 `http://127.0.0.1:5178/`，服务地址 `/runtime`，临时测试令牌 `mobile-live-review`。自动验收6次额度用完后，页面提供明确按钮开放另6次手动调用；不会自动开放或追加计费。每次调用最多1024输出token，工具续答也计数。密钥仅在进程内存，重启同一临时数据目录保留已用额度。
